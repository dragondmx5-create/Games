# UNDRAL Android build carrier

This branch stores the GitHub-ready UNDRAL source archive as ordered Base64
chunks. The workflow at `.github/workflows/undral-native-android.yml`
reconstructs the archive on a GitHub-hosted runner and builds the Vulkan/NDK
debug APK.
